# Mahjong

Egyszerű, böngészőben futó Mahjong pasziánsz, külső függőségek nélkül (HTML + CSS + JavaScript).

## Indítás

Nyisd meg az `index.html` fájlt egy böngészőben.

## Szabályok

- Párosíts össze két egyforma szabad követ, ekkor mindkettő eltűnik.
- Egy kő akkor szabad, ha nincs rajta másik kő, és a bal vagy a jobb oldala üres.
- A virágok bármelyik virággal, az évszakok bármelyik évszakkal párosíthatók.
- Akkor nyersz, ha mind a 144 követ eltüntetted.

Minden leosztás garantáltan megoldható.

## Gombok és billentyűk

| Gomb | Billentyű | Funkció |
|------|-----------|---------|
| 💡 Tipp | `H` | Megmutat egy lehetséges párt |
| ↶ Vissza | `U` / `Ctrl+Z` | Visszavonja az utolsó lépést |
| 🔀 Keverés | `S` | Újrakeveri a maradék köveket (megoldható módon) |
| ✦ Új játék | `N` | Új leosztás |
